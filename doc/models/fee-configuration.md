
# Fee Configuration

Fee configuration including category and distribution details. All monetary fields within this object (`totalAmount`, `transactionAmount`, `valueAmount`, and the `amount` on each distribution entry) are **always non-negative** on responses. ([learn more](page:concepts/monetary-precision#quote-responses-are-always-non-negative))

*This model accepts additional fields of type Object.*

## Structure

`FeeConfiguration`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `category` | `String` | Optional | High-level category for a transactional record on a [Receipt](page:resources/receipts) — `COMPANY` (a company / funding-account-side entry) or `USER` (a payee-side entry). Used in receipt-detail breakdowns to identify which party of a transaction the line item describes. See [Receipt Details](page:additional-api-information/receipt-details) for the full breakdown structure. |
| `distribution` | [`Array[FeeDistribution]`](../../doc/models/fee-distribution.md) | Optional | Array of fee distribution details for each responsible party |
| `source` | `String` | Optional | What triggered a fee — `TRANSACTION` (the fee was generated by a money-movement event such as a bank transfer or card purchase) or `USER` (the fee was generated by a user-driven action such as account enrollment or paper-statement request). Appears on [Receipt](page:resources/receipts) line items so reconciliation pipelines can group fees by origin. |
| `total_amount` | `String` | Optional | Total amount of money for all transactions, represented as a string to preserve decimal precision ([learn more](page:concepts/monetary-precision)) |
| `transaction_amount` | `String` | Optional | Total amount of money for the transaction, represented as a string to preserve decimal precision ([learn more](page:concepts/monetary-precision)) |
| `type` | `String` | Optional | Type of fee assessed against an account, wallet, or prepaid card — examples include `BANK_TRANSFER`, `INSTANT_PAYMENT`, `PLASTIC_CARD_ISSUANCE`, `MONTHLY_MAINTENANCE_ACTIVE_ACCOUNT`, `FOREIGN_EXCHANGE_CONVERSION`, and many more. Each fee on a [Receipt](page:resources/receipts) carries this identifier so it can be reconciled against the program's fee schedule. The exact set of fees a program is subject to is configured by PayQuicker at onboarding. |
| `value_amount` | `String` | Optional | Value of the target resource, represented as a string to preserve decimal precision ([learn more](page:concepts/monetary-precision)) |
| `value_type` | `String` | Optional | How a fee amount is calculated — `STATIC` (a fixed amount regardless of transaction size) or `PERCENTAGE` (a percentage of the transaction amount). Surfaced on [Receipt](page:resources/receipts) line items alongside the `[__Fees](page:additional-api-information/receipt-details)` identifier so the calculation can be reconciled against the program's fee schedule. |
| `destination_country` | `String` | Optional | ISO 3166-1 alpha-2 country code (two-letter, e.g., `US`, `GB`, `DE`). Used throughout the PayQuicker API in place of the full country name — for residential / mailing addresses on [Users](page:resources/users), for the registered country of [bank-account](page:resources/instruments) and [electronic-wallet](page:resources/instruments) instruments, and to gate which destinations / methods are available to a payee. See [Country Codes](page:additional-api-information/country-codes) for the supported list. |
| `destination_currency` | `String` | Optional | ISO 4217 three-letter currency code (e.g. `USD`, `EUR`, `GBP`). See [Currency Codes](page:additional-api-information/currency-codes) for the supported list.<br><br>**Default**: `'USD'` |
| `additional_properties` | `Hash[String, Object]` | Optional | - |

## Example

```ruby
fee_configuration = FeeConfiguration.new(
  category: 'COMPANY',
  distribution: [
    FeeDistribution.new(
      amount: '1.02',
      currency: 'USD',
      description: 'string',
      formatted_amount: '$0.05 USD',
      percentage: '50.00',
      responsibility: 'COMPANY',
      responsibility_source: 'CREDIT',
      source_token: 'acct-3908ab5a-6ce1-474d-8b80-a63a7b147860',
      additional_properties: {
        'exampleAdditionalProperty' => JSON.parse('{"key1":"val1","key2":"val2"}')
      }
    )
  ],
  source: 'TRANSACTION',
  total_amount: '50.00',
  transaction_amount: '50.00',
  type: 'BANK_TRANSFER_REVERSAL_STOP_NOC',
  value_amount: 'string',
  value_type: 'PERCENTAGE',
  additional_properties: {
    'exampleAdditionalProperty' => JSON.parse('{"key1":"val1","key2":"val2"}')
  }
)
```
