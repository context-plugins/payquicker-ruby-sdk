# Documents

---


The *Documents* resource manages files attached to a user — typically identity-verification documents (driver's license, passport, proof of address) uploaded as part of onboarding or KYC remediation. Documents have a status indicating whether they have been provided, accepted, or rejected.

> **Program type:** API Gateway only. Hosted Portal payees upload documents through the hosted portal UI.

With this resource, you can perform the following requests:

* `POST /documents` — Upload a new document
* `GET /documents/{document-token}` — Fetch a document by token
* `PUT /documents/{document-token}` — Replace an existing document
* `POST /documents/search` + `GET /documents/search/{searchId}` — Search documents
* `POST /documents/requirements/search` + `GET /documents/requirements/search/{searchId}` — Discover what document types a given user / scenario requires before prompting the payee

Documents follow the platform's standard search pattern. See [Searching](page:concepts/searching).

For more information, see [Documents](page:resources/documents). For a step-by-step guide, see [Upload a Document](page:howtos/upload-a-document).

# Create Document

Upload a [document](page:resources/documents). Include `scope` as a query parameter. Uses multipart/form-data.

```ruby
def create_document(user_token,
                    fields,
                    upload,
                    accept_language: 'en-US',
                    accept_timezone: 'UTC')
```

This endpoint requires [server](../../doc/auth/oauth-2-client-credentials-grant.md)
